## 3. Existing Entry Points Mapped

1. **GP-on-PCA Forward Surrogate Entry Point:**
   - Class: `GPonPCASurrogate` in `inverse-design-em/src/models/gp_pca.py`
   - Methods:
     - `fit(X, Y)`: $X \in \mathbb{R}^{N \times 2}$ in $[0, 1]$, $Y \in \mathbb{R}^{N \times 562}$ in GHz.
     - `predict(X, return_std=True)`: returns `(Y_pred, Y_std)` where $Y \in \mathbb{R}^{N \times 562}$.

2. **Inverse Design Engine Entry Point:**
   - Class: `InverseDesignEngine` in `inverse-design-em/src/inverse.py`
   - Methods:
     - `predict_design(l1_um, l2_um, return_std=True)`: forward surrogate evaluation at arbitrary $(L_1, L_2)$.
     - `inverse_target_curve(target_f1, target_f2, grid_resolution=200, top_k=5)`: global screening + L-BFGS-B refinement.
     - `run_roundtrip_test(held_out_index)`: round-trip verification on held-out design.

## 4. Gap Analysis vs. PLAN.md §3 Target Architecture

The following components defined in PLAN.md §3 are currently missing and must be developed in the upcoming tickets:

1. **Standardized Data Contract (`data/processed/bands.npz`):**
   - Current state: `inverse-design-em/data/processed/F.npy` contains the $F$ tensor, but lacks structured fields `L1_um`, `L2_um`, `k` in a single `.npz` archive.
   - Action for T0.2: Generate and validate `data/processed/bands.npz` per `AGENTS.md`.

2. **Core Library Modules (`src/invdes/`):**
   - `splits.py`: Single source of truth for design-level splits (LODO, checkerboard, leave-one-edge-out, blind hooks).
   - `metrics.py`: Standardized metrics contract (MAE, RMSE, max error, band gap features, group velocity excluding kink indices 90 and 190).
   - `kpath.py`: Mapping $k \in [0.1, 2.9]$ to Brillouin zone path coordinates.

3. **Pre-Registered Criteria & Physics Spec (`configs/`):**
   - `criteria.yaml`: Pre-registered evaluation thresholds committed before experiments.
   - `geometry_spec.yaml`: Human intake template for physical geometry, materials, and solver settings.

4. **Multi-Fidelity & Physics Modules (Phases 2–4):**
   - `pinn/`: Soft physics loss regularizers and physics-regularized MLP.
   - `physics/`: Differentiable analytical Plane-Wave Expansion (PWE) eigensolver and calibration.
   - `multifidelity/`: Differentiable residual $\Delta$-GP and hybrid forward model.

5. **Reporting & Results Infrastructure:**
   - `results/` directory for programmatic JSON output.
   - `reports/` directory for script-generated markdown summaries.
